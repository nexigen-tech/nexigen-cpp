# Навык анализа C++ проектов

Используй этот навык, когда пользователь просит проанализировать структуру, метрики, объём или сложность C++ кода в текущем репозитории.

## Инструкция по выполнению для Агента:
1. Убедись, что в системе установлены утилиты `cloc` и библиотека `lizard` (через pip). Если их нет, вежливо попроси пользователя установить их или используй доступный пакетный менеджер.
2. Запусти скрипт анализа, находящийся в этой же папке: `python3 ./analyzer.py .` (где `.` — путь к анализируемому проекту).
3. Прочитай сгенерированный JSON-отчет. Структура отчета:
   - `project` — основной код проекта (без `/examples`);
   - `examples` — файлы из верхнеуровневой директории `/examples`;
   - `total` — суммарные метрики.
4. **Правило отдельного анализа examples:** выводи пользователю красивый, структурированный markdown-отчет, обязательно содержащий ДВА отдельных раздела:
   - «Основной проект» — метрики, ключевые выводы и рекомендации по ключу `project`;
   - «Примеры (`/examples`)» — метрики, ключевые выводы и рекомендации по ключу `examples`.
   В конце добавь краткий сводный раздел «Итого» по ключу `total`.
5. Рекомендации по рефакторингу сложных функций формулируй внутри соответствующего раздела: функции из `/examples` упоминаются только в разделе примеров, даже если их сложность высокая (примеры — допустимое место для длинного `main`).
