---
description: Генерация Doxygen-комментариев для C++ заголовков на основе OpenSpec
---
Изучи заголовочный файл `$ARGUMENTS` и соответствующие ему спецификации в `openspec/specs/`.
Добавь в заголовочный файл исчерпывающие комментарии в формате Doxygen (`///`):
- `@brief` и подробное описание назначения класса/функции.
- `@tparam` для всех параметров шаблонов и концептов C++.
- `@param` и `@return` для методов.
- `@note` с отсылкой к контрактам из OpenSpec (если применимо).
Не меняй логику и сигнатуры C++ кода.
