# Покрыть тестом пустое состояние toolbar в nexigen-canview

Status: resolved
Type: task

## Контекст

В рабочем дереве уже есть изменение `tools/nexigen-canview/ui/canview_window.cpp`
(`draw_toolbar_actions`): если ни одна view не сфокусирована, toolbar показывает
только `Import session` и не рисует Pause/Clone/Rename с нулевым указателем.
Изменение не было привязано к отдельной задаче и не покрыто тестом.

## Что сделать

- Добавить headless-тест ImGui (или вынести решение о состоянии toolbar в чистую
  функцию над `UiState`), проверяющий:
  - при пустом списке views доступна только `Import session`;
  - при наличии views без фокуса выбирается первая view;
  - Pause/Clone/Rename не рисуются без сфокусированной view.
- Если тест невозможен без полноценного ImGui-контекста, зафиксировать это здесь
  и оставить изменение под ручную приёмку.

## Resolution

Решение о состоянии toolbar вынесено в модель: `CanViewModel::ensure_focused()`
возвращает сфокусированную view, выбирает первую при отсутствии фокуса и
возвращает `nullptr` для пустого списка. `draw_toolbar_actions` теперь использует
только этот результат, без дублирования логики и без разыменования нулевого
указателя.

Покрытие: `tools/nexigen-canview/tests/views_test.cpp::test_ensure_focused_state`
проверяет пустую модель, автофокус первой view, сохранение существующего фокуса
и возврат к пустому состоянию после удаления последней view. Само рисование
кнопок остаётся под существующими xvfb-тестами `nexigen_canview_ui_*`.
